# 🛒 Amazon Clone (HTML & CSS Only)

This is a simple **Amazon Clone UI project** built using only **HTML and CSS**.  
It is created for learning and practice purposes to improve front-end development skills.

---

## 📌 Features

- Responsive navigation bar
- Amazon-style homepage layout
- Product grid sections
- Banner/hero section
- Footer similar to Amazon UI
- Clean and structured UI design

---

## 🛠️ Technologies Used

- HTML5
- CSS3

---

## 🎯 Purpose of Project

This project was built to:
- Practice HTML structure
- Improve CSS styling skills
- Understand layout design
- Learn how real e-commerce UI designs are structured
